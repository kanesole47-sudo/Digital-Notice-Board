# 🏫 College Notice Board

A smart, targeted college notice distribution system built with Python & Streamlit.

## Features
- 📢 Admin can send notices to specific streams, years, and divisions
- 🔴 Urgent notice popups with acknowledge/ignore buttons
- 🔖 Save and download notices
- 📊 Read analytics for admins
- 📱 Mobile-friendly PWA (installable on Android & iOS)

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Tech Stack
- Python + Streamlit
- SQLAlchemy + SQLite
- bcrypt for authentication
